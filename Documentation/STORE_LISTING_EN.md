# Hero Defense — Store Listing Draft (EN)

## Short description

Build defenses, command heroes, and survive waves with an automatically produced army.

## Full description

Hero Defense is an offline landscape strategy defense game. Place production buildings, deploy swordsmen, archers, mages, and other units, then turn the battle with each hero's active skill and ultimate. Create a different upgrade combination each run and challenge elite enemies, bosses, four stages, multiple difficulties, and endless mode.

- Six heroes with distinct combat roles
- Six production buildings and automatic unit combat
- Four stages, difficulty settings, and endless defense
- Three-choice roguelike battle upgrades
- Permanent progression, unlocks, collection, and achievements
- Core play works offline

Languages: Korean and English structure (professional localization review required before release)
