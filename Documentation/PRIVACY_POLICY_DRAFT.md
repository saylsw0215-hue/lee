# 개인정보 처리방침 초안

이 문서는 법률 자문이 아니며 출시 지역과 실제 포함 SDK를 기준으로 전문가 검토가 필요합니다.

Hero Defense의 현재 출시 후보는 계정, 광고, 분석 서버를 사용하지 않으며 이름·연락처·위치·사진·카메라·마이크·광고 식별자를 수집하지 않습니다. 게임 진행, 설정, 업적과 해금 정보는 기기의 Unity `persistentDataPath`에 저장됩니다. 설정의 **게임 데이터 초기화**로 게임 내 로컬 데이터를 삭제할 수 있으며 앱 삭제 또는 운영체제 백업 정책에 따른 실제 삭제·복원 방식은 플랫폼에 따라 달라질 수 있습니다.

외부 SDK: Unity 엔진과 프로젝트 manifest에 명시된 Unity 공식 패키지 이외의 분석·광고 SDK 없음.

정책 변경 시 스토어 설명 또는 공개 정책 페이지에 시행일과 변경 내용을 고지해야 합니다.
