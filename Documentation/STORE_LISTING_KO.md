# Hero Defense — 스토어 설명 초안 (KO)

## 짧은 설명

건물을 세우고 영웅과 자동 전투 부대를 이끌어 끝없는 몬스터 공세를 막아내세요.

## 전체 설명

Hero Defense는 오프라인으로 즐기는 가로형 전략 디펜스 게임입니다. 전장에 생산 건물을 배치하고 검사, 궁수, 마법사 등 다양한 부대를 자동 생산하세요. 영웅의 스킬과 궁극기를 적절한 순간에 사용하고, 매 전투 달라지는 강화 조합으로 정예 몬스터와 강력한 보스에 맞서세요.

- 6명의 영웅과 고유 스킬
- 6종 생산 건물과 자동 전투 유닛
- 4개 스테이지, 난이도와 무한 모드
- 로그라이크 3지선다 강화
- 영구 성장, 해금, 도감과 업적
- 네트워크 없이 기본 플레이 가능

지원 언어: 한국어, 영어 구조 제공(출시 전 번역 감수 필요)

개인정보: 외부 계정·광고·분석 SDK 없이 진행 정보를 기기에 로컬 저장합니다. 자세한 내용은 공개될 개인정보 처리방침을 확인하세요.
